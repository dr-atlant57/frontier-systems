Anthroponomy / PRIMORDIS

A person is not only a current profile. Human development is a changing system with possible trajectories and roles.

Architecture brief / conceptual design. This describes a proposed system and next steps, not a completed deployment.

01 / ROOT

The architectural problem

Static assessment describes the present while ignoring the distinction between current capacity, future potential, environmental dependencies and the sequence of development. The same label can conceal very different trajectories.

02 / DESIGN

Proposed architecture

Create a navigation model that connects present state, projected potential, available paths, dependencies and observable progress without reducing the person to a fixed score.

System components

State ontology

Identify dimensions of the current situation, roles, environment and relevant constraints.

Potential space

Describe possible future states and the conditions under which they become reachable.

Development graph

Represent interventions, opportunities, constraints and feedback as a sequence of transitions.

Personal navigation

Offer inspectable choices and allow the model to evolve as real observations arrive.

03 / RESEARCH

Critical validation questions

  1. Which observations describe state and which describe an interpretation?
  2. How can uncertainty in a proposed future trajectory be represented?
  3. What forms of feedback improve practical navigation without overfitting the person to a score?

Development pathway

State model → potential map → development pathways → longitudinal feedback → partner applications
